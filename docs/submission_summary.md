# ISE-A2 Result Summary (248 words)

This report carries the ISE-A1 clinic appointment project into a formal domain model and testable specification. The proposed system coordinates non-emergency outpatient appointments using a clinic-configured arrival window followed by on-site check-in and queue-ticket issuance. The domain vocabulary distinguishes Appointment, ClinicWindow, QueueTicket and AuditEvent, and separates the appointment lifecycle from the queue-ticket lifecycle. This avoids treating a booking confirmation as proof that a patient is physically present.

The process and state models define booking, cancellation, check-in, late-arrival review, no-show reconciliation, calling and consultation completion. The data dictionary records types, meanings, trusted authorities, validation rules and privacy boundaries. Six invariants cover valid time windows, appointment/time consistency, one active ticket per appointment, ticket issuance only after accepted check-in, authorised no-show recording, and legal queue-state transitions. A decision table makes the arrival-window boundaries explicit: the start is inclusive, the end is exclusive, and reaching the end of the grace period makes a booking eligible for staff review rather than automatically declaring a no-show. The 15-minute grace period is a configurable prototype assumption, not a known clinic policy.

A small Python reference model was checked with 36 unit tests using synthetic examples; all 36 passed in the recorded run. This demonstrates internal consistency of the selected rules, not clinical effectiveness or production readiness. Public Chinese outpatient research and official privacy/cybersecurity materials inform the context, but no target-clinic data, interview, pilot or stakeholder validation is claimed. A real deployment would require clinic approval of policies, access roles, retention and fallback procedures.
