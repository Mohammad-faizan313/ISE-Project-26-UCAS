# Source / implementation boundary

The A1 artifact is an evidence brief rather than a production clinic system.

The proposed semester implementation should be limited to:
- patient appointment-window booking
- arrival/check-in confirmation
- queue-state management
- no-show / cancellation / late-arrival states
- clinic staff dashboard
- assisted/manual fallback

Excluded at A1:
- diagnosis or clinical decision support
- electronic medical records
- payments and insurance
- emergency care
- hospital-wide interoperability
- autonomous clinical prioritisation
